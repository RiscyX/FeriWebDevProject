# 🧊 MyFridge – Smart Recipe Finder

MyFridge is a responsive web application that helps users find recipe ideas based on the ingredients they already have at home.
It offers a clean interface, smart filtering, and three access levels — guest, registered user, and administrator — to ensure a complete cooking and management experience.

## 🍽️ Features

### 👤 Guest

Browse all recipes by category

View general information about the site

Register for a personal account

### 🧾 Registered User

Add new recipes (name, ingredients, image, description, estimated cost)

Browse and search recipes by category or keyword

Use the “My Fridge” feature to get recipe suggestions from available ingredients

Manage profile information (password, name, phone number, etc.)

Create a personal weekly menu from favorite recipes

Save, edit, and delete favorite recipes

Request password reset via email

### 🛠️ Administrator

Manage recipe categories and ingredients

Add, modify, or delete recipes

Approve or reject submitted user recipes (with email notification)

Manage user accounts (ban/unban users, control login permissions)

## 🧊 “My Fridge” Functionality

The My Fridge tool allows users to add ingredients they currently have and automatically receive recipe suggestions that match them.

Recipes missing up to two ingredients are still displayed, with missing items visually highlighted.

Ingredients can be added or removed using a drag-and-drop interface.
